Module 1 · PACE: Purpose

Set the Stage — AI Governance & Visual Assets

In this module you'll learn foundational AI governance principles, get oriented to Microsoft CoPilot, and build your first AI-assisted visual asset concept.

Key Takeaways
  • AI governance means using AI responsibly within your organization's framework — you are always the final author.
  • What you put in is what you get out — specificity in prompts drives quality.
  • The RTCF formula: Role · Task · Context · Format.
Your Activity

Use Microsoft CoPilot to generate a design brief for a visual learning asset. Then open PowerPoint and start building from CoPilot's output.

🟢
Beginner Prompt Template

"You are a learning designer. Create a visual learning asset concept for a [TOPIC] training aimed at [AUDIENCE]. Describe the layout, key visual elements, colors, and icons to use. Format it as a design brief I can use in PowerPoint."

🔵
Intermediate Challenge

Build your own RTCF prompt. Iterate at least twice. Compare outputs and note what changed and why.

Reflection Space

Notes: What surprised you about the output? What would you change in your next prompt?

Module 2 · PACE: Augment

Build the Asset — AI Integration & Written Assets

In this module you'll use CoPilot and Microsoft 365 together as an integrated workflow and draft one written learning asset of your choice.

Key Takeaways
  • CoPilot writes and structures; Microsoft 365 (Word/PowerPoint) designs and publishes — together they're powerful.
  • Different asset types need different prompt structures — context is everything.
  • Iteration is design, not failure.
Choose Your Asset
🟢
Beginner Templates

Facilitator Guide: "Write a 2-minute facilitator guide intro for a [TOPIC] session for [AUDIENCE]. Include a welcome, session goal, and warm-up question."

Video Script: "Write a 90-second video script about [TOPIC] for [AUDIENCE]. Include an opening, 3 key points, and a call to action."

🔵
Intermediate Challenge

Write your own RTCF prompt. Run it. Identify one gap. Add a refinement line. Regenerate. Compare versions 1 and 2.

Self-Assessment
  • Accuracy — Is this factually correct for my context?
  • Alignment — Does it achieve my learning objective?
  • Voice — Does it sound like my organization?

Notes: What would you change about your prompt next time?

Module 3 · PACE: Curate + Embed

Proof of Concept — Human Review & Workflow Integration

In this module you'll apply a human review process, combine your assets into a proof of concept, and map PACE to your own design workflow.

Human Review Checklist
  • Factual accuracy verified
  • Aligned to learning objective
  • Reflects organizational voice
  • No sensitive or inappropriate content
  • Accessible and inclusive language
  • Meets your org's AI disclosure policy
My PACE Framework Card
  • P — Purpose: My learning need is ___
  • A — Augment: I will use CoPilot for ___ and Microsoft 365 for ___
  • C — Curate: My review process will include ___
  • E — Embed: This asset will live in ___ in my workflow

Your Take-Home Resources

🖼 Visual Asset Prompt

You are an instructional designer and visual design consultant. Create a design brief for a [ASSET TYPE] on [TOPIC]. Audience: [AUDIENCE]. Tone: [TONE]. Include: layout, color palette, typography, key icons, headline text. Format for Microsoft PowerPoint.

📄 Facilitator Guide Prompt

You are an instructional designer. Write a facilitator guide intro for a [DURATION]-minute session on [TOPIC] for [AUDIENCE]. Include: welcome, 3 session goals, warm-up question, timing guidance. Tone: professional and encouraging.

🎙 Podcast Script Prompt

You are a podcast producer for a professional development series. Write a 90-second intro script for "[EPISODE TITLE]." Host: [DESCRIPTION]. Audience: [AUDIENCE]. Start with a hook. End with a preview. Tone: [TONE].

🎬 Video Script Prompt

Write a [DURATION]-second video script on [TOPIC] for [AUDIENCE]. Scene 1: hook/problem (15s). Scene 2: key insight (30s). Scene 3: example (25s). Scene 4: call to action (10s). Tone: [TONE].

The PACE Framework — Your Reference Card

P

Purpose

Define the learning need. Apply governance. Ask: Is AI right for this asset? Am I working within my organization's approved tools and guidelines?

A

Augment

Prompt with RTCF. Iterate. Use CoPilot for content, Microsoft 365 for design and publishing. What you put in is what you get out.

C

Curate

Human review always. Check accuracy, alignment, tone, inclusion. You are the author.

E

Embed

Map to your ADDIE/SAM workflow. Build reusable templates. Scale across your team.
